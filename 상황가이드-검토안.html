「지금 어떤 상황?」 검토안

만들려는 것

사용자가 자기 상황 카드를 클릭하면 맞는 도구로 안내해주는 모달 하나,
그리고 그 모달을 다시 부르는 사이드바 작은 버튼 하나.

목적: 첫 사용자에게 5초 각인 + 작업 중 헤맬 때 한 번 클릭으로 도구 가이드.

① 카드 문구 (한국어)

큰 카드 3개 — 가장 흔한 상황

  1. 🌅 어제까지 뭘 했는지 기억이 안 나요 → Resume
  2. 💭 AI 답이 너무 길어져서 위로 다시 못 올라가요 → Compress
  3. 🧱 큰 수정 들어가는데 망칠까 봐 무서워요 → Backup

작은 줄 5개 — 모달 하단

  1. 🔄 AI 가 우리가 정한 거 자꾸 까먹어요 → Anchors
  2. 🧭 다음에 뭘 할지 모르겠어요 → Next
  3. 🚨 AI 가 큰 실수 했는데 되돌리고 싶어요 → Restore
  4. 📋 오늘 한 일 정리해두고 싶어요 → Summary
  5. 🗂 옛 파일 여러 개 합치고 싶어요 → Consolidate

① 카드 문구 (영어 — 영어권 메이커 톤)

Big cards (3)

  1. 🌅 I lost track of where I left off → Resume
  2. 💭 This chat is too long — I can't scroll back to find anything → Compress
  3. 🧱 About to make a big change. Don't want to break what's working → Backup

Small lines (5)

  1. 🔄 The AI keeps forgetting decisions we already made → Anchors
  2. 🧭 Not sure what to do next → Next
  3. 🚨 The AI just made a mess — I want to roll back → Restore
  4. 📋 Want to wrap up what I did today → Summary
  5. 🗂 I have a bunch of old notes I want to merge → Consolidate

② 사이드바 버튼 후보

  • A 추천   🧭 도와줘 — 짧고 친근, 평시에 누르기 부담 없음
  • B   🤔 지금 어떤 상황? — 명확하지만 좁은 공간에 길음
  • C   💡 뭘 쓸지 모르겠어요 — "내가 모른다" 인정 부담
  • D   🆘 도움말 — FAQ 같은 무거운 느낌

③ 첫 진입 모달 헤드라인

지금 어떤 상황이세요?

AI 와 작업하면서 가장 자주 부딪히는 순간들이에요.
가까운 걸 골라주세요. 우리가 어떻게 돕는지 보여드릴게요.

④ 모달이 자동으로 뜨는 시점

  • A 추천   앱 첫 실행 시만 자동. 닫으면 끝. 이후엔 사이드바 버튼으로만 접근. 사용자 짜증 없음.
  • B   카드 한 번도 클릭 안 했으면 매번 자동. 한 번 클릭하면 자동 사라짐. 끈질김. 짜증 가능성.

작업 정보

작업 시간: 3~4시간
새로 만들 것: 모달 1개, 사이드바 버튼 1개, localStorage 플래그 1개
기존 변경 없음: 7개 프롬프트, 폴더 구조, 저장 흐름 모두 그대로

답해주실 4가지

  1. 카드 1~8번 문구 중 바꾸고 싶은 거 있나요?
  2. 사이드바 버튼: A / B / C / D 중 또는 직접
  3. 헤드라인·부제: 그대로 OK 또는 수정안
  4. 트리거 시점: A 또는 B
