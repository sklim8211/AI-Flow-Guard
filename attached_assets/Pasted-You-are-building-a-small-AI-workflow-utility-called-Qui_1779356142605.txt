You are building a small AI workflow utility called:

Quiet Question Sidecar

This is NOT a dashboard.
This is NOT a project management tool.
This is NOT an AI replacement.

The product is:

A quiet sidecar that helps people keep flow while working with AI.

The feeling should be:

* calm
* lightweight
* minimal
* always nearby
* non-intrusive
* Apple-like utility feeling
* small floating helper
* fast open/close
* designed for daily AI work sessions

⸻

Core Concept

When people work with AI for long conversations, they lose:

* context
* flow
* decisions
* next steps
* important moments

This tool helps users:

* resume work
* summarize work
* extract anchors
* compress current state
* prepare next actions

BUT:

The tool itself does NOT summarize.

Instead:

The tool provides high-quality standardized prompts that users copy into AI systems like ChatGPT or Claude.

The AI performs the actual summarization.

The user saves the result.

Example Flow

“Resume Work”
