PART 4 — File limit enforcement
─────────────────────────────────

When user tries to save a file:
- Count total files across all folders 
  in localStorage
- If count >= 50 AND qq_license_key does 
  NOT exist in localStorage:
  - Block the save action
  - Show modal:
    Title: "You've reached the free plan limit"
    Message: "You've saved 50 files. 
    Upgrade to Pro for unlimited saves."
    Primary button: "Upgrade to Pro →"
    → opens plan selection modal from PART 1
    Secondary button: "Not now"
    → closes modal, save is cancelled

If qq_license_key exists in localStorage:
- No file limit. Save proceeds normally.
