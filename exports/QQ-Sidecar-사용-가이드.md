# QQ Sidecar 사용 가이드

> ChatGPT나 Claude로 일하다 보면 **"내가 어디까지 했었지?"**가 자꾸 끊깁니다.
> QQ Sidecar는 이걸 막아주는 작은 옆 도우미예요.

---

## 먼저 이것만 알아두세요

이 앱은 **AI에 직접 연결되지 않습니다.** 우리가 AI를 부르지도 않고, 여러분의 AI 대화를 엿보지도 않아요.

대신 이렇게 작동합니다:

```
[QQ Sidecar 아이콘 클릭]
        ↓
표준 프롬프트가 자동으로 클립보드에 카피됨
        ↓
ChatGPT/Claude에 붙여넣기 (Ctrl+V)
        ↓
AI가 정해진 형식으로 답변
        ↓
답변을 카피해서 📋 클립보드 저장 아이콘 클릭
        ↓
앱이 내용을 보고 알맞은 폴더에 자동 저장
```

**여러분이 할 일은 카피 → 붙여넣기 → 카피 → 저장**, 이게 전부입니다.

---

## 아이콘 한눈에 보기

| 아이콘 | 이름 | 한 줄로 |
|------|-----|--------|
| 📋 | **클립보드에서 저장** | AI 답변을 1클릭으로 알맞은 폴더에 저장 |
| 🟢 | **Resume** | "어디까지 했었지?"를 AI에게 재구성시킴 |
| 📝 | **Summary** | 오늘 작업한 걸 한 장으로 요약 |
| ⚓ | **Anchors** | "왜 그렇게 결정했더라"를 잊지 않게 따로 보관 |
| ⏭️ | **Next** | "그래서 지금 뭘 해야 하지?" 정리 |
| 🗜️ | **Compress** | 너무 길어진 대화를 한 장으로 압축 |
| 🛡️ | **Backup** | 큰 수정 직전, 돌아갈 수 있는 안전망 만들기 |
| 🔄 | **Restore** | 백업으로 작업 상태 되돌리기 |
| 🚨 | **SOS** | 위기 상황에 적절한 도구 찾아주는 길잡이 |
| 🗂️ | **Consolidate** | 흩어진 옛 파일들을 한 장으로 합치기 |

## 📋 클립보드에서 저장

> **AI에게 받은 답변을 1클릭으로 저장하는 입구**

### 언제 쓰나요
다른 아이콘으로 만든 프롬프트를 AI에 붙여넣고, **AI 답변을 받았을 때**. 그 답변을 카피한 뒤 이 아이콘을 누르면 끝.

### 어떻게 작동해요
- 답변 첫머리에 **정해진 형식의 정보(메타 헤더)**가 있으면 → 폴더·파일명을 자동으로 인식
- 화면에 "✨ 자동 인식됨" 표시가 뜨고, 그대로 [저장] 누르면 끝
- 정보가 없으면 → 일단 `DRAFTS` 폴더에 저장 (나중에 정리)

### 작은 팁
- 같은 이름의 파일이 이미 있으면 노란 경고가 뜹니다 → **"새로 만들기"가 기본**(안전 우선)
- 정말 덮어쓰고 싶으면 라디오로 선택

---

## 🟢 Resume — 이어서 작업하기

> **"내가 어디까지 했었지?"** 가 흐릿할 때

### 언제 쓰나요
- 어제 작업하다 멈춘 ChatGPT 대화를 오늘 새 창에서 이어가고 싶을 때
- 며칠 만에 프로젝트로 돌아왔을 때
- AI 대화창이 너무 길어져서 새 창을 열어야 할 때

### 어떻게 작동해요
1. 아이콘 클릭 → 표준 프롬프트가 카피됨
2. AI에 붙여넣기 → AI가 **"현재 상태 / 최근 결정 / 막힌 점 / 다음 할 일"** 형식으로 정리해줌
3. 그 답변을 📋로 저장 → **CURRENT 폴더**에 들어감
4. 다음에 작업 재개할 때 이 파일을 새 AI 대화에 붙이면 바로 이어감

### 작은 팁
- 워크플로(개발/글쓰기/리서치/디자인/전략)에 따라 같은 Resume도 다른 질문을 합니다. 개발자에겐 "아키텍처 상태"를, 작가에겐 "현재 서사"를 묻는 식.

---

## 📝 Summary — 작업 요약

> **오늘 뭐 했는지 한 장으로 정리하고 싶을 때**

### 언제 쓰나요
- 작업 세션을 마무리할 때
- "오늘 일 마치기" 버튼 누르기 전
- 누군가에게 진행 상황을 공유해야 할 때

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트 카피
2. AI에 붙임 → AI가 **"완료한 것 / 기술 변경 / 발견 / 미해결 / 방향"** 형식으로 요약
3. 답변을 📋로 저장 → **SUMMARIES 폴더**에 누적

### 작은 팁
- 매일 누적되면 "이번 달 뭐 했지"를 한눈에 볼 수 있는 작업 일지가 됩니다
- 너무 많아지면 🗂 Consolidate로 여러 개를 한 장으로 합쳐도 좋습니다

---

## ⚓ Anchors — 핵심 결정 추출

> **"왜 그렇게 결정했더라"** 를 잊지 않으려고

### 언제 쓰나요
- 큰 결정을 내린 직후 ("Stripe 대신 Toss 쓰기로 결정")
- 토론·고민 끝에 방향을 정했을 때
- 나중에 "이 결정을 누가 왜 했지?"가 헷갈릴 만한 시점에

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트 카피
2. AI에 붙임 → AI가 **결정 + 그 이유 + 포기한 것 + 제약 조건**을 정리
3. 답변을 📋로 저장 → **ANCHORS 폴더**에 누적

### 작은 팁
- 몇 주만 지나도 "왜 그 선택을 했더라" 가 흐릿해집니다. Anchors는 **미래의 나에게 보내는 메모**예요
- 한 줄 메모보다 강력합니다 — AI가 "포기한 것까지" 같이 기록해주거든요

---

## ⏭️ Next — 다음 할 일

> **"그래서 지금 뭘 해야 하지?"** 가 흐릿할 때

### 언제 쓰나요
- 작업을 시작했는데 우선순위가 정리 안 될 때
- 막막함이 몰려올 때
- 내일 할 일을 정리하고 싶을 때

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트 카피
2. AI에 붙임 → AI가 **"지금 당장 / 오늘 / 이번 주 / 막힌 것"** 순서로 우선순위를 잡아줌
3. 답변을 📋로 저장 → **NEXT 폴더**에 들어감

### 작은 팁
- "오늘" 탭의 **다음 할 일** 섹션에 자동으로 표시됩니다

---

## 🗜️ Compress — 컨텍스트 압축

> **AI 대화가 너무 길어졌을 때, 새 창으로 이사 가는 짐싸기**

### 언제 쓰나요
- ChatGPT/Claude가 "대화가 너무 길다"고 경고하기 시작할 때
- 새 대화창을 열고 싶지만 지금까지의 맥락을 다 끌고 가고 싶을 때
- 컨텍스트가 잘릴 위험을 느낄 때

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트 카피
2. **지금 길어진 AI 대화창**에 붙임 → AI가 **"배경 / 현재 상태 / 제약 / 다음"**의 짧은 압축본을 만들어줌
3. 답변을 📋로 저장 → **CURRENT 폴더**에 들어감
4. **새 AI 대화창을 열고** 이 압축본을 맨 처음에 붙임 → 바로 이어감

### 작은 팁
- Resume과 비슷해 보이지만 목적이 다릅니다:
  - **Resume**: 다른 날 작업 이어가기 (재진입용)
  - **Compress**: 같은 작업을 새 창으로 옮기기 (이사용)

---

## 🛡️ Backup — 안전망 스냅샷

> **큰 수정 직전, "망쳤을 때 돌아갈 한 장" 만들기**

### 언제 쓰나요
- 코드/문서를 크게 뜯어고치기 직전
- 위험한 결정을 시도하기 전
- "이게 잘못되면 돌이키기 힘들겠는데" 싶을 때

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트 카피
2. AI에 붙임 → AI가 **현재 상태 + 진행 중 + 다음 단계 + 결정 이유 + 절대 잃으면 안 되는 정보 + 위험 요소**를 자세히 정리
3. 답변을 📋로 저장 → **SAFE 폴더**에 들어감
4. 자동으로 **v1, v2, v3 버전 번호**가 붙고, **위험도(낮음/중간/높음)**도 표시됨

### 작은 팁
- 다른 요약과 달리 **"복원 힌트"**가 들어있어서, 나중에 Restore로 되살릴 때 핵심 단서가 됩니다
- 일주일에 한 번이라도 큰 작업 전에 백업 습관 들이면 든든해요

---

## 🔄 Restore — 백업으로 되돌리기

> **작업이 꼬였을 때, 안전망으로 돌아가기**

### 언제 쓰나요
- 큰 수정 후 일이 꼬여서 이전 상태로 되돌리고 싶을 때
- 며칠 전 작업했던 상태를 다시 펼치고 싶을 때

### 어떻게 작동해요
1. 아이콘 클릭 → 프롬프트가 카피됨
2. Workspace에서 **SAFE 폴더의 백업 파일을 열어 내용 카피**
3. AI 대화창에 프롬프트 붙이고, 끝에 백업 내용까지 붙임
4. AI가 백업을 읽고 **"이 시점은 v몇이고, 무슨 상태였고, 지금 가장 먼저 해야 할 일은 OO"** 형식으로 풀어 설명해줌

### 작은 팁
- Restore는 답변에 메타 정보가 없어서 자동 분류는 안 됩니다 (DRAFTS로 들어가거나, CURRENT로 수동 저장)
- "되돌리기"보다는 **"백업 시점의 작업 환경을 AI 머릿속에 다시 띄우기"**에 가깝습니다

---

## 🚨 SOS — 위기 상황 가이드

> **"지금 뭘 써야 할지 모르겠는데 큰일 났어요"**

### 언제 쓰나요
- 패닉 상태에서 어떤 도구를 쓸지 판단이 안 설 때

### 어떻게 작동해요
아이콘을 누르면 3가지 카드가 뜹니다:

- 🗜️ **"지금 너무 길어졌어요"** → Compress로 이동
- 🛡️ **"큰 수정 직전이에요"** → Backup으로 이동
- 🔄 **"꼬여서 되돌리고 싶어요"** → Restore로 이동

상황만 고르면 알맞은 도구로 데려다줍니다.

---

## 🗂️ Consolidate — 옛 파일 합치기

> **흩어진 옛 파일들을 한 장으로 깔끔하게**

### 언제 쓰나요
- 같은 주제의 요약/결정 파일들이 10개 넘게 쌓였을 때
- "예전 메모가 너무 많아서 뭐가 최신인지 모르겠어"
- 프로젝트가 한 단계 마무리되어 정리하고 싶을 때

### 어떻게 작동해요
1. **Workspace 탭** 열기
2. 우측 위 **"선택"** 토글 켜기 → 파일 옆에 체크박스가 나타남
3. 합치고 싶은 파일 **2개 이상** 체크
4. 하단에 뜨는 **"🗂 N개 합치기"** 버튼 클릭
5. 우리 앱이 모든 파일 내용을 프롬프트에 자동으로 첨부해 활성 패널에 띄움 → 사용자는 그냥 카피
6. AI에 붙임 → AI가 중복은 빼고, 새로운 정보 우선으로 한 장으로 합쳐줌
7. 답변을 📋로 저장 → 합쳐진 결과의 종류에 따라 알맞은 폴더로 자동 분류

### 작은 팁
- **원본은 자동 삭제 안 합니다.** 합쳐진 결과를 직접 확인한 뒤, 원본 파일들을 지울지는 사용자가 결정하세요
- 결과 파일 안에 **"어떤 원본들에서 합쳤는지"** 자동 기록됩니다 → 나중에 추적 가능

## 자주 묻는 질문

### Q. AI 답변에 이상한 형식(`---` 같은 것)이 들어있는데 정상인가요?
네, 정상입니다. 그게 **메타 정보**예요. 우리 앱이 그걸 보고 폴더와 파일명을 자동으로 정해줍니다. 메타 정보 덕분에 여러분이 매번 "어느 폴더에 둘까", "파일명 뭐로 할까"를 고민할 필요가 없어요.

### Q. AI가 메타 정보를 안 만들어줘요
지시를 따르지 않는 AI라면 모델을 바꿔보세요(ChatGPT 4o / Claude Sonnet 정도면 충분히 따라옵니다). 메타 정보가 없으면 일단 `DRAFTS` 폴더에 저장되고, 사용자가 수동으로 정리하시면 됩니다.

### Q. 파일이 어디에 저장되나요?
브라우저(localStorage)에 기본 저장됩니다. Workspace 탭에서 **"폴더 연결"**을 하면 로컬 PC의 폴더에도 같이 저장돼서 더 안전해집니다 (Chrome/Edge에서만 지원).

### Q. 이 앱은 인터넷 연결이 필요한가요?
**아니요.** 모든 작업이 여러분 브라우저 안에서 일어납니다. AI 작업도 여러분이 직접 ChatGPT/Claude 사이트로 가서 하는 거고, 우리는 그 사이에 끼지 않아요.

### Q. 데이터가 어디론가 전송되나요?
**전송되지 않습니다.** 백엔드 서버가 아예 없고, 분석·트래킹도 없습니다. 여러분의 작업 기록은 오직 여러분 브라우저(또는 연결한 로컬 폴더)에만 있습니다.

## 워크플로 5종 — 한 줄 안내

프로젝트를 만들 때 워크플로를 고르면, **Resume / Summary / Anchors / Next** 4개 아이콘이 그 분야에 맞는 질문으로 변합니다:

- 💻 **개발** — 아키텍처, 기술 결정, 코드 변경 중심
- ✍️ **글쓰기** — 서사, 감정, 톤, 인물 결정 중심
- 🔍 **리서치** — 가설, 발견, 증거, 가정 중심
- 🎨 **디자인** — UX 원칙, 비주얼 결정, 사용성 중심
- 🧭 **전략·기획** — 가설, 시장 신호, 전략 결정 중심

같은 프로젝트라도 어울리는 워크플로를 고르면 더 정확한 정리를 받을 수 있어요.

## 추천 사용 패턴

### 👶 처음 시작하는 분
1. 프로젝트 만들기 → 워크플로 고르기
2. ChatGPT/Claude로 작업하다가 한 덩어리 끝나면 → **Summary** 한 번 돌리기
3. 큰 결정 했으면 → **Anchors** 한 번
4. 작업 마칠 때 → **"오늘 일 마치기"** 버튼

이 4가지만 해도 일주일치 작업이 깔끔하게 쌓입니다.

### 🏃 일상적으로 쓰는 분
- 매일 시작: **Resume** 으로 어제 컨텍스트 띄우기
- 중요한 결정: **Anchors**
- 막막할 때: **Next**
- 큰 수정 전: 반드시 **Backup**
- 대화 길어지면: **Compress** 로 새 창 이사

### 🧘 가끔만 쓰는 분
- 작업할 때마다 부담 갖지 마세요
